# solidcraft-generators: catalogue part generators for SolidCraft

Type a manufacturer's ordering code (`MGN12H2R300Z0C`, `HFS5-2020-497.5-TPW-LEV-REH`) and get a native SolidCraft design of that exact part.
Every dimension comes from the manufacturer's published catalogue, is cited by page and table, and is checked automatically on the
built part for every listed code. Each generator is built from SolidCraft's own command layer (`solidcraft-cli run` with a JSON
command list).

## Use

```
tools/gen MGN12H2R300Z0C                  # -> out/MGN12H2R300Z0C.sc  (--step for STEP, --opt caps for an option)
tools/check                               # every generator: build each code in codes.txt, run the spec check, write checks/
tools/check vendors/hiwin/mg/rail-set     # one generator
tools/shots MGN12H2R300Z0C                # EN and DE screenshots, Donate / Discord hidden
tools/provenance && tools/lint && tools/build-index
```

`SC_VER` (default 0.50.0) picks the SolidCraft release; `SC_CLI`, `SC_APP`, `SC_RELEASES` say where the binaries are; `SC_SHOTS_TOOLS` is a prefix holding Xvfb
and ImageMagick for the screenshots. Python 3.11 or newer, no packages.

## Add a generator

1. `vendors/<vendor>/<series>/<generator>/`: copy the shape of an existing one (CONTRIBUTING.md has the checklist).
2. Put every dimension in `data/*.csv` with a source id and page per row; cite the source in `sources.toml`; write `generator.toml` with its `[declares]`.
3. List the codes to test in `codes.txt` (valid, invalid with `!`, options), write `src/check.py`.
4. `tools/check <dir>`, `tools/preview <dir>`, `tools/provenance <dir>`, `tools/lint`, `tools/build-index`.
5. Add the row to the table above and open one pull request for that generator.

A generator below the "Checked" level (every code in codes.txt passing its spec check) is not given an index entry.

Language: the generators here are Python host-side scripts that call solidcraft-cli.
